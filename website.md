Agent Process:
You build the agent by creating separate folders for each important part. Then you ask the ai to connect the sections using the vercel ai suite or whatever backend agent scripts you are using.

Directory
Agents
Sub Agents: all of the delegated process that can be done to split up work
Skills: Repeatable workflows that an agent can apply to execute any task
Tools: The platforms and services you want your agent to access and perform
Functions: Specific tasks that can be used in any workflow
Knowledge: all of the data you have access to, including user data, documentation and industry best practices
Memory: The technical ability for your agent to remember all past history
Instructions: What you tell your agent to do, for every circumstance or all around
Harness: The combination of agents, skills, tools, functions etc to direct your agent
Runtime: The processes it uses to create the end product or artifact
Gateway: The ability to connect to different LLM providers and communications services
Sandbox: The ability for the agent to perform real code in a safe environment (not on drive)
Start a google drive folder. Create the subfolders, then load the data and type the content you want. Ask the agent to fill in the in between.

For example, for tools, you can have a sub folder call tools and just open up a google doc or spreadsheet and write: email, crm, etc. Then simply ask your agent to create "MCP Servers"
