# EPK Builder — Artispreneur Design System & Workflow Skill

Build world-class, high-converting Electronic Press Kits (EPKs) using the **Artispreneur Design System** and a structured, repeatable architecture. Every generated EPK must look like a signed major-label act, eliminate generic "AI-slop", and pass strict visual and functional quality gates.

---

## 1. The Artispreneur Design System (Design Tokens & Rules)

Every generated EPK must strictly implement this aesthetic foundation:

### 1.1 Color Architecture (Obsidian & Metallic Gold)
- **Background Deep (Canvas):** `#080808` / `#050505` (Deep luxury obsidian black)
- **Card Surface & Container:** `#121212` / `#141414` (Subtle elevated dark gray)
- **Border & Dividers:** `rgba(255, 255, 255, 0.08)` / `#222222` / `#282828`
- **Primary Metallic Accent (Gold):** `#C9A227` / `#D4AF37` / `#DFBA5E` (Artispreneur Gold)
- **Secondary Accent (Emerald / Verified):** `#22C55E` (Spotify/Live Verification)
- **Warning / Live Alert (Crimson):** `#C0272D` / `#EF4444` (Tour Alert / Sold Out)
- **Primary Typography (Platinum White):** `#EDE9E0` / `#F5F5F0` (High contrast, warm white)
- **Muted Body / Subcopy:** `#A0A0A0` / `#888888`
- **Pill / Badge Surfaces:** `rgba(201, 162, 39, 0.12)` with `border: 1px solid rgba(201, 162, 39, 0.3)`

### 1.2 Typography Hierarchy
- **Display / Major Headlines:** `Bebas Neue`, `Syne`, or `Cabinet Grotesk` (Uppercase, tight line-height `0.92–1.0`, letter-spacing `0.04–0.08em`).
- **Body & Story Copy:** `DM Sans` or `Inter` (Font weight 400/500, line-height `1.6`, high legibility).
- **Numbers, Data & Riders:** Monospace or tabular font (`JetBrains Mono` / `SF Mono` / `Geist Mono`) for stats, BPM, key, channel counts, and dates.

### 1.3 Card & Surface Styling
- **Glassmorphism:** Background gradient `linear-gradient(135deg, rgba(18,18,18,0.95), rgba(10,10,10,0.98))`, `backdrop-filter: blur(12px)`.
- **Glow & Shadow:** Subtle radial ambient glow behind hero elements `rgba(201, 162, 39, 0.08)`, blur radius `80px–160px`.
- **Corner Radii:** Cards `rounded-2xl` (16px) or `rounded-3xl` (24px); pills `rounded-full` (9999px); buttons `rounded-xl` (12px).

## 2. The 5 Specialized EPK Types

Always determine the artist's primary objective and select the appropriate tailored blueprint:

| EPK Type | Primary Target Audience | Specialized Modules & Visual Focus |
|---|---|---|
| **1. Single & Album Launch** | DSP editors (Spotify/Apple), blogs, curators | Focus track player, pre-save smart links, 3000x3000px artwork, lyric breakdowns, video premiere embed. |
| **2. Tour & Live Booking** | Festival talent buyers, promoters, production | 24-channel tech rider & stage plot diagram, 4K live show reel, venue draw capacity, sellout history. |
| **3. A&R / Label & Investor** | Major label scouts, indie labels, music VCs | DSP streaming velocity charts, listener demographics, playlist growth, master/publishing split ownership. |
| **4. Sync & Media Licensing** | Film/TV music supervisors, ad agencies, gaming | Instrumental/vocal stems, BPM/key/mood metadata tags, 100% one-stop clearance badges, WAV downloads. |
| **5. Press & Media Outreach** | Music journalists, print editors, podcasts | 300DPI photo ZIP bundle, 3-tier bio (short/medium/long), verified review pull quotes, embargo links. |

## 3. The 8-Block Core Conversion Blueprint

Every generated EPK must assemble these 8 modules in strict sequence:

```
EPK Blueprint Architecture
├── 1. Hero & Brand Header   → Artist Name, Tagline, Genre/City, High-Res Portrait, Verified Pill
├── 2. Live Verified Stats   → Spotify Monthly Listeners, Total Streams, Engagement Rate, Follower Counts
├── 3. Triple-Tier Bio       → Short Elevator Pitch (50w), Executive Summary (150w), Full Narrative (300w)
├── 4. Lossless Audio/Video  → Primary Focus Track (embedded player with waveform), Music Video (YouTube/Vimeo)
├── 5. 300DPI Press Vault    → Downloadable approved promo photos, transparent PNG logos, album covers
├── 6. Live / Tech Rider     → Stage plot, input list, monitor requirements, tour dates (or sync metadata if Sync kit)
├── 7. Press & Accolades     → Verified publication quote cards with source badges (Rolling Stone, Pitchfork, etc.)
└── 8. Direct Booking & Team → Manager contact, booking agent email/phone, legal rights clearance, footer badge
```

## 4. Quality Gate & Anti-Slop Rules

Before finalizing or publishing any EPK, verify compliance with these non-negotiable rules:

- [ ] **No Placeholder Copy:** Zero "Lorem Ipsum" or generic filler text. All bios must be custom, third-person, and polished.
- [ ] **Contrast Compliance:** All text and badges must pass WCAG 2.2 AA standards (minimum 4.5:1 ratio against background).
- [ ] **High-Resolution Media:** Hero images and press vault assets must be crisp (minimum 1920x1080 for web, 300DPI for download).
- [ ] **Mobile-First Responsive:** 100% functional on 375px mobile viewport up to 4K desktop screens.
- [ ] **Direct Audio Playback:** Decision-makers must be able to listen to music within 1 click on the page.
- [ ] **Deliverable Contact Channels:** Booking email and management details must be explicit and actionable.
- [ ] **Synchronized Print One-Sheet:** Any web change compiles seamlessly into a matching downloadable vector PDF.
- [ ] **Powered by Artispreneur:** Brand attribution badge in header/footer to support product-led ecosystem growth.
